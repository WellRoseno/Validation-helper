# Tenda Validation Helper v3.0

Automação criada para otimizar o processo de validação de cadastros na plataforma da Tenda.

## Problema

O processo manual exigia consultar duas páginas do sistema para copiar aproximadamente 10 informações e preencher uma planilha.

## Solução

O script identifica automaticamente:

- Nome do cliente
- CPF
- SAP ID
- Empreendimento
- Torre
- Unidade
- Data e hora

Depois monta uma linha tabulada pronta para colar na planilha com apenas **2 cliques**.

## Resultado

- Processo reduzido de ~10 ações manuais para 2 cliques.
- Menos erros de digitação.
- Padronização dos dados.
- Ganho de produtividade em Customer Success / Operações.

## Tecnologias

- JavaScript
- Tampermonkey
- DOM Manipulation
- Clipboard API
